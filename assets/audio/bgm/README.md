# BGM（音源未配置）

外部素材・仮の無音ファイルは収録していません。権利を確認した以下の音源を追加してください。

- `menu.mp3`: 静かな和モダン。木・水・風を感じる、柔らかな明るさ。
- `play.mp3`: menuより静かな、集中を妨げないアンビエント。

ボーカル、強いビート、派手な琴やファンファーレは不要です。ループ端にクリックや大きな音量差がない音源を用意してください。
追加後は `src/audio/sources.ts` の該当する `null` を静的 `require('../../assets/audio/bgm/menu.mp3')` / `require('../../assets/audio/bgm/play.mp3')` に変更します。
ファイルを置くだけでは有効になりません。出典・利用許諾をREADMEに記録し、iOS/Androidを再ビルドして試聴してください。
