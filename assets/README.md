# 正式アセット

提供されたPNGを加工せず配置しています。

| ファイル | サイズ | 形式・用途 |
| --- | --- | --- |
| icon.png | 1024×1024 | RGB、不透明。iOS・共通アイコン |
| adaptive-icon.png | 1024×1024 | RGBA、外周透過。Android前景 |
| splash.png | 1242×2688 | RGB。起動画面 |

背景色は `#F7F4EC`。スプラッシュはSDK 55の `expo-splash-screen` プラグインで
`imageWidth: 200` / `resizeMode: contain` を指定しています。
縦長の提供画像全体を縮小表示するため、中央の絵は小さく表示されます。
Androidの起動画面はOSのアイコン領域内に表示され、元の縦長画像が全画面になる設定ではありません。

Adaptive Iconは主要な色の重なりが中央に収まりますが、外周の紙・装飾と色カードの端は
マスクによって切れる可能性があります。円形・角丸など各ランチャーで実機確認してください。
iOS用画像は正方形・不透明ですが、提供画像内に角丸の輪郭が描かれているためOSの角丸との見え方も確認してください。
デザインは変更していません。

アイコン・スプラッシュの確認にはネイティブビルドが必要です。
Expo GoやWebではストア配布時の起動画面を検証できません。
